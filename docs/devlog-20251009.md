  # 2025/10/09 Lord 战队机器人开发方向讨论

## 1. 大致方向
经过小组成员的讨论，我们初步确定了一号机器人顶部收集为主，二号机器人底部收集后转移给一号机器人的整体思路。  
1号机器人的主要职责是在“好好先生”打开之前到达其正下方，通过机械机构尽量保证从“好好先生”落下的大部分弹丸落入收集仓  
2号机器人的主要职责是收集地上散落的弹丸，并择机将弹丸送给一号。  

## 2. 机器人能力
### 1. 一号机器人
1. 通过桥梁
2. 顶部收集
3. 底部收集
4. 跨越斜坡地形
### 2. 二号机器人
1. 底部收集
2. 转移收集的弹丸

## 3. 机器人结构
### 1. 一号机器人
1. 底盘  
赛事方提供的官方物资。
2. 轮子  
赛事方提供的麦克纳姆轮，位于底板下方，通过TT马达与底板形成刚性连接。
3. 收集仓  
自行设计的收集仓，用于收集弹丸。
4. 底部收集器
一个类似于网球收集器的笼装结构，用于收集在底部的弹丸。
### 2. 二号机器人
1. 底盘  
赛事方提供的官方物资。
2. 轮子  
赛事方提供的麦克纳姆轮，位于底板下方，通过TT马达与底板形成刚性连接。
3. 底部收集器  
由一个聚集器、一个毛刷滚轴组成，用于收集地上散落的弹丸
4. 底部储存器
由一个传送带、一个单向挡板、一个尾部舱门组成，用于临时储存弹丸并在特定时间将弹丸送给一号机器人。

## 4. 开发要点
1. 机器人结构设计需要能够实现机器人能力。
2. 机器人控制算法需要能够最大限度发挥机器人性能，对于过桥等场景应仔细适配。
3. 机器人强度应当符合规则和比赛需要。
4. 机器人应当使用模块化设计，方便后续升级。
